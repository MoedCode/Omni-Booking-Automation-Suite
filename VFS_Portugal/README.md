# vfs_portugal

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run 
```

This project was created using `bun init` in bun v1.3.14. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

**الخلاصة الفاصلة لدور خادم Vite في العمليات السابقة**

خادم Vite يعمل كـ **شاشة عرض ومترجم واجهة فقط**؛ هو المسؤول عن جعل الجدول والأزرار مرسومة بألوانها أمامك، لكنه لا يعلم شيئاً عن الإكسيل، لا يستدعي Puppeteer، ولا يتحكم في فتح وإغلاق النوافذ. كل المهام الحقيقية تُدار عبر `gui/main.js` بالتواصل مع كود البوت ونظام التشغيل.
